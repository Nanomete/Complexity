# Complexity
Rate growth times in algorithms (speed of code program) 

# What is the Complexity?
It indicates the growth rate of an algorithm. The higher the growth rate, the slower the algorithm becomes because it requires more time. Conversely, the lower the growth rate, the faster it runs.

<h2>Algorithm Growth Rate and Complexity Comparison</h2>

$$
 O(1)\ <\ O(log\ n)\ <\ O(\sqrt n)\ <\ O(n)<O(n\ log\ n)\ <\ O(n^2)\ <\ O(2^n)\ <\ O(n!) < O(n^n)
$$

<h4>
Low Growth Rate (Good Algorithms) :
</h4>

$$
O(1), \ O(log\ n), \ O(\sqrt{n}) \
$$

<h4>
Medium Growth Rate :
</h4>

$$
O(n), \ O(n\ log\ n), \ O(n^2)
$$

<h4>
High Growth Rate (Bad Algorithms):
</h4>

$$
O(2^n), \ O(n!), \ O(n^n) \
$$
